## 设备范围与发布步骤

当前 TensorRT 构建资源仅有 `sm89`；已验证设备为 RTX 4060 Laptop GPU。其他 GPU 架构未验证，不能宣传为适用于全部 NVIDIA 显卡。安装包不附带显卡驱动，尚未进行数字签名。

1. 确认上表剩余的来源、权限和项目授权决定，形成明确的核对记录。
2. 把补充的许可证全文、版权声明及适用条款纳入安装包资源，重新构建完整版。旧安装包的校验值不适用于重建产物。
3. 对重建安装包重新生成资源清单与 SHA-256，并执行干净环境安装测试。
4. 为 GitHub 的 `v1.0.0` 发行添加安装包、校验文件、中文安装说明及第三方声明；为 Gitee 创建同一标签的发行并上传相同文件。若平台上传大小限制不允许，则使用明确的镜像下载地址，不应把大型二进制提交进普通 Git。
5. 核对两个平台的附件名称、大小、校验值及说明一致，并明确硬件限制和未签名状态。
